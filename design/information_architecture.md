# 觅诗 App 信息架构（IA）

## 1. 一级导航
- 首页（地图）
- 附近
- 播放
- 我的

## 2. 页面结构树
- 启动页
  - 权限引导（定位、通知、媒体）
- 首页（地图）
  - 季节推荐入口
  - 当前定位
  - 附近诗词点位
  - 到地推荐卡
  - 打卡入口
  - 诗词详情入口
- 附近
  - 列表视图（距离/热度排序）
  - 筛选（朝代/诗人/主题）
  - 点位详情入口
- 诗词详情
  - 诗词正文
  - 季节标签（最佳体验季节/节气）
  - 注释与译文
  - 背景故事
  - 权威解读（多版本）
  - 语音朗读入口
  - AI 动画入口
  - 收藏/分享
- 播放页
  - 音频播放控件
  - 文本同步高亮
  - 背景音设置
- AI 动画任务页
  - 任务状态（排队/生成中/完成/失败）
  - 结果预览与保存
- 我的
  - 收藏
  - 足迹
  - 旅行打卡
  - 打卡图谱
  - 历史记录
  - 设置
- 旅行路线
  - 城市诗词路线（半日/一日）
  - 路线详情与打卡进度
- 设置
  - 权限管理
  - 通知策略
  - 清理缓存
  - 隐私条款

## 3. 关键信息流
1. 位置流：定位 -> 围栏命中 -> 季节加权推荐卡
2. 内容流：推荐卡 -> 诗词详情 -> 解读/故事/人物
3. 打卡流：到地触发 -> 一键打卡 -> 打卡卡片生成 -> 分享/路线进度更新
4. 媒体流：详情 -> 朗读播放 或 AI 动画任务
5. 反馈流：收藏/分享/播放完成/打卡 -> 埋点回传 -> 推荐优化

## 4. 主要实体
- 用户
- 地点（POI）
- 历史地名映射
- 诗词
- 诗人
- 解读内容
- 语音资源
- AI 视频任务
- 用户行为事件
- 打卡记录
- 季节标签

## 5. 状态定义
- 地点命中状态：未命中 / 高置信命中 / 低置信待确认
- 打卡状态：未打卡 / 可打卡 / 已打卡
- AI 任务状态：创建 / 排队 / 生成中 / 成功 / 失败 / 过期
- 内容状态：草稿 / 一审 / 二审 / 发布 / 下线
