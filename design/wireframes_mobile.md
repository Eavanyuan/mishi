# 觅诗 App 移动端线框说明（Wireframes）

## 1. 启动与权限流
### 页面 A：启动页
- 顶部：品牌名“觅诗”与一句文案
- 中部：古风山水插画背景
- 底部：按钮“开启诗意旅程”

### 页面 B：权限引导
- 卡片 1：定位权限（用于到地推荐）
- 卡片 2：通知权限（用于触发提醒）
- 卡片 3：媒体权限（用于保存动画）
- 底部：`同意并继续`

## 2. 首页地图
### 页面 C：地图首页
- 顶部：搜索框（地名/诗词/诗人）
- 中部：地图 + 当前位置 + 诗词点位标记
- 下方浮层：最近推荐卡（题名/作者/距离/导语/季节标签）
- 底部：Tab 导航（首页/附近/播放/我的）

### 页面 D：到地推荐弹层
- 标题：此地有诗
- 内容：诗词题名 + 一句核心诗句 + 当前季节提示
- CTA：`去感受`、`立即打卡`、`稍后提醒`

## 3. 诗词详情
### 页面 E：诗词详情页
- 顶部：地点名 + 古今地名标签
- 主体：题名、作者、朝代、正文、最佳体验季节标签
- 分段模块：注释、译文、背景故事、人物关系、权威解读
- 固定底栏：`朗读`、`生成动画`、`收藏`、`分享`

### 页面 F：权威解读切换
- Tab：教材版 / 学术版 / 通俗版
- 每段解读展示来源与更新时间

## 4. 音频播放
### 页面 G：播放页
- 封面：诗词意境图
- 中间：诗句随播放高亮滚动
- 底部：播放控制（播放/暂停、进度、倍速、背景音）

## 5. AI 动画
### 页面 H：动画生成页
- 输入区：风格（写意/写实）、时长（15/30s）
- 提交按钮：`开始生成`
- 状态区：排队人数、预计等待时间

### 页面 I：动画结果页
- 视频预览
- 按钮：`保存本地`、`分享`、`再次生成`

## 6. 我的
### 页面 J：个人中心
- 模块：收藏、足迹地图、旅行打卡、历史、生成记录、设置

## 7. 旅行打卡
### 页面 K：打卡弹层
- 内容：地点、诗句、季节标签、打卡时间
- 按钮：`确认打卡`、`生成打卡卡片`

### 页面 L：旅行路线页
- 内容：城市诗词路线（半日/一日）、路线点位与已打卡进度
- 按钮：`开始路线`、`继续打卡`

## 8. 交互规范（线框级）
- 关键操作可达：单手拇指区内完成核心操作
- 地图与详情切换：保持上下文（返回后保留位置）
- 失败兜底：定位失败、网络失败、视频生成失败均提供明确重试入口
- 打卡反馈：打卡成功后即时动效反馈，并支持一键分享
