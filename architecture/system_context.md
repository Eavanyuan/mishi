# 觅诗系统上下文（Task 3）

## 1. 目标
构建一个基于地理位置触发的古诗词沉浸式平台，支持季节加权推荐、旅行地诗词打卡、权威解读、语音朗读与可选 AI 场景动画。

## 2. 系统边界
### 2.1 系统内
- 移动端 App（iOS/Android）
- API Gateway
- Content Service（诗词内容）
- Geo Service（定位与古今地名）
- Recommend Service（推荐与排序）
- Checkin & Route Service（打卡与路线）
- Media Service（音视频资产）
- AI Orchestrator（LLM/TTS/视频生成编排）
- CMS 后台（内容录入、审核、发布）
- Observability（日志、指标、告警）

### 2.2 系统外
- 地图与定位服务（高德/腾讯）
- Push 通知服务（APNs/FCM）
- 对象存储与 CDN
- AI 模型服务（LLM、TTS、视频生成）
- 天气/时段数据源（可选）

## 3. 核心业务流
1. 用户授权定位并进入首页。
2. Geo Service 进行围栏命中 + 古今地名映射。
3. Recommend Service 结合距离、热度、时段、季节因子输出推荐。
4. 客户端展示“到地推荐卡”（含季节标签/节气）。
5. 用户进入详情，查看权威解读，播放语音，按需触发动画生成。
6. 用户可执行打卡，Checkin Service 记录并更新路线进度。
7. 行为埋点回流，用于推荐优化与运营分析。

## 4. 非功能约束
- 核心接口 P95 < 300ms（不含视频生成）
- 打卡写入幂等，避免重复打卡
- AI 生成异步化，任务可重试可追踪
- 所有内容可追溯来源并可审计

## 5. 安全与合规
- 用户鉴权：JWT + Refresh Token
- 最小化定位数据存储，敏感字段脱敏
- AI 请求与内容审核日志留痕
- 版权来源与版本管理强制校验
