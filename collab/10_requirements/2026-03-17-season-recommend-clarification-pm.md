## 3. 业务规则确认

### 3.1 季节匹配度计算标准

**建议采用架构文档方案，理由**:

1. **部分匹配 0.8 更合理**: 
   - 多季节诗词（如《钱塘湖春行》标注["春","夏"]）在春季应获得较高分数
   - 0.8 比 0.7 更能体现"部分匹配"的价值

2. **无标注诗词给中性分 0.5**:
   - 避免过度惩罚无季节标注的优质诗词
   - 保留内容多样性，不强制所有诗词都必须标注季节

**最终规则确认**:

```python
def season_score(poem_seasons, current_season):
    """
    季节匹配度计算规则
    
    参数:
    - poem_seasons: 诗词标注的季节列表,如 ["春"] 或 ["春","夏"]
    - current_season: 当前季节,如 "春"
    
    返回值: 0.0-1.0
    """
    if not poem_seasons:  # 无季节标注
        return 0.5  # 中性分数
    
    if current_season in poem_seasons:
        if len(poem_seasons) == 1:
            return 1.0  # 完全匹配
        else:
            return 0.8  # 部分匹配 (多季节诗词)
    else:
        return 0.3  # 跨季阅读
```
